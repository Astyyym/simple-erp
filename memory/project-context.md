# 项目定位与业务背景

## 是什么

本地单机销售/退货/拿货/退拿货开单、客户商品资料与账款系统，面向消防器材门店。
Flask + SQLite，可选 Windows PyWebView 桌面壳，**只在 Windows 运行**（WSL 只通过盘映射做可选交叉测试）。

- 正式目录 = 本仓库根（唯一真源）
- GitHub `Astyyym/simple-erp`，默认分支 `main`
- 版本以根目录 `VERSION` 为准

## 门店真实使用场景（直接影响需求判断）

- **高频用销售单、退货单；拿货/退拿货基本不开**（功能保留，但不要当主路径去优化）。
- **对账方式**：打印客户账单，与对方账目相减；周期不固定（一个月 / 20 天 / 3 个月都有），不是固定月结。
- **迁移承接口径**：旧软件的历史单据**不导入**，只把截至迁移日的**未结欠款**落到客户期初余额；欠款明细不进系统。
  - 依据：`开发短计划/2026-10-08_旧数据迁移承接与备份恢复_执行计划.md`（第 19 行）

## 已确认的业务口径（长期）

- **售价唯一来源 = 开单学习出的客户专属价**（2026-10-15 用户决策）：商品档案不再有「默认价」
  ——建档/编辑/导入/导出/列表/回收站都不再有该字段；客户对该商品有专属价则开单自动带出，
  没有则单价**留空**手输。手输价 **> 0** 就写为该客户对该商品的专属价（0 元不学）；
  换客户时按新客户重取，新客户没有专属价就**清空**（不保留上一个客户的价）。
  依据：`开发短计划/2026-10-15_商品售价来源收敛与专属价查看_执行计划.md`。
  `products.default_price_cents` 列仍保留（不删列 = 不写迁移），值恒 0、代码不再读。
- 商品管理列表「专属价」列是查看入口，「编辑」按钮文案为「查看详情」；编辑页有「客户专属价」卡片。
