# 项目专属记忆索引

本目录是简单ERP 的**项目专属长期记忆**：只记「每次进项目都该知道的长期事实」。

**读取时机**：进入本项目后先读本文件，再按下面的索引按需读取。

## 文件

| 文件 | 放什么 |
|---|---|
| [project-context.md](./project-context.md) | 项目定位、门店真实使用场景、已确认的业务口径 |
| [environment.md](./environment.md) | 本机环境与本项目技术栈的实测边界 |
| [pitfalls.md](./pitfalls.md) | 踩过的坑，含「别被假现象骗了」类 |

## 边界（什么不该写这里）

| 内容类型 | 归属 |
|---|---|
| 可复用的业务规则 / 操作流程 / 实测方法（含 README 与截图方法） | `skills/simple-business-erp-development/references/` |
| 产品规格、当前实现事实 | `docs/需求/` |
| 一次性执行过程、阶段状态 | `开发短计划/`、根目录 `task_plan.md` / `findings.md` / `progress.md` |
| 每轮必须遵守的硬规则 | `AGENTS.md` 正文（本目录不会被自动加载，硬规则不能只放这里） |

## 写入约束

- 新记忆**只写本目录**，不写回 Hermes 全局记忆；全局记忆也不重复本项目细节。
- 本目录随 git 提交：不得写真实订单/客户数据、日志、密钥、个人联系信息。
- 每条结论尽量带证据指针（源码 `path:line`、测试、reference、短计划），便于日后核对是否仍成立。
- 结论过期就直接改成当前正确内容，不留「已过时」标记。
