## 文档职责

- 当前产品做什么：`docs/需求/消防器材店ERP系统-需求文档.md`
- 专题规则和决策来历：`docs/需求/` 下对应专题记录
- 长期项目规矩：根目录 `AGENTS.md`
- 本轮怎么改、验什么：`开发短计划/` 中对应执行计划；先查索引，只有交付目标/验收范围不同才另开一份（该目录为本地私有记录，不随公开仓库发布，故正文以路径引用）
- 多阶段任务当前进度：根目录 `task_plan.md`、`findings.md`、`progress.md`；只跟踪一个当前跨会话任务，短任务不建三件套
- 项目专用稳定流程：`skills/simple-business-erp-development/`，由 `AGENTS.md` 路由

任务关闭后，将仍有效的产品事实归入对应需求文档或项目技能 reference，并把短计划标为历史记录。`task_plan.md`、`findings.md`、`progress.md` 是同一活动任务的临时跟踪文件，不作为跨任务的第二套知识库；具体清理前须核实 Git 状态并保留用户已有未提交内容。当前根目录三件套保留历史内容并标明非本次库存任务；本次进度集中在库存短计划，不覆盖旧记录。详细规则见项目技能的 `Planning and task-record lifecycle`。
