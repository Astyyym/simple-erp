# 消防ERP 当前开发说明

## 启动

开发环境（WSL）：

```bash
cd '/mnt/d/wenjian/Hermes/ERP系统'
source .venv/bin/activate
PYTHONPATH=app python app/app.py
```

Windows 日常启动入口：

- 第一次准备：双击 `setup.bat`
- 日常使用：双击 `启动系统.vbs`
- 出问题停止：双击 `停止系统.bat`

## 已实现范围

- Flask + SQLite + Jinja2 项目骨架
- SQLite WAL、schema_version、完整性检查
- 安全备份 zip：包含 erp.db、config.json、backup_info.txt、integrity_check.txt
- 审计日志基础表
- 商品/客户/客户专属价格基础页面
- 开单、保存、PDF生成、确认打印、作废基础页面
- 客户总账余额计算：期初 + saved/printed订单 + active调整 - active收款
- 金额用整数“分”存储，页面格式化为元

## 验证命令

```bash
source .venv/bin/activate
PYTHONPATH=app pytest tests/ -q
PYTHONPATH=app python app/app.py
```

然后访问：

- http://127.0.0.1:5000/health
- http://127.0.0.1:5000/
