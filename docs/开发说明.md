# 简单ERP 开发说明

## 启动

### 双环境职责

- 唯一正式源码：`D:\wenjian\Hermes\简单ERP`
- Windows：日常开发、桌面流程、打包和最终验收
- WSL：通过 `/mnt/d` 使用同一份源码，按需进行 Linux 交叉测试；不维护第二份长期仓库

### WSL 交叉测试与源码预览（5001）

```bash
cd '/mnt/d/wenjian/Hermes/简单ERP'
ERP_PORT=5001 PYTHONPATH=app .venv/bin/python app/app.py
```

Windows 浏览器访问 WSL IP，例如：

```text
http://172.17.x.x:5001
```

不要与正式 EXE 的 `127.0.0.1:5000` 混用。

### Windows 脚本入口

- 第一次准备：`setup.bat`
- 日常使用：`启动系统.vbs` 或 `启动系统.bat`
- 停止：`停止系统.bat`
- WSL 双击入口（仅开发机）：`启动系统-WSL版.bat` / `停止系统-WSL版.bat`

## 测试

```bash
cd '/mnt/d/wenjian/Hermes/简单ERP'
PYTHONPATH=app .venv/bin/python -m pytest tests/ -q
```

健康检查：

```text
http://127.0.0.1:5001/health
```

正式 EXE：

```text
http://127.0.0.1:5000/health
```
