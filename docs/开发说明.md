# 简单ERP 开发说明

## 开发环境职责

- 唯一正式源码：本地 Windows 仓库根目录。
- Windows：主开发、桌面流程、打包和最终验收。
- WSL：可经 Windows 盘映射访问同一份源码做交叉测试；不要在 WSL 另外维护长期仓库。
- Windows 源码服务默认使用 `127.0.0.1:5000`。开发预览不要和旧 EXE/Waitress 混用端口；涉及用户页面验收前先确认端口对应的进程和源码目录。

## Windows 源码运行

首次准备源码虚拟环境：

```bat
setup.bat
```

运行 Flask 源码服务：

```bat
启动系统.bat
```

`启动系统.vbs` 会静默调用同目录的 `启动系统.bat`。桌面正式版使用 `dist\简单ERP\简单ERP.exe`，不要用 WSL Python 打包 Windows EXE。

## 测试

从项目根目录运行：

```bat
.venv\Scripts\python.exe -m pytest tests\ -q
```

若正在使用打包环境，也可运行：

```bat
.venv-win\Scripts\python.exe -m pytest tests\ -q
```

本次盘点使用 `.venv-win` 完整运行：`96 passed`。`tests/conftest.py` 会为每个测试创建临时运行目录和 SQLite 数据库；不要删除或改写正式 `data/erp.db` 来准备测试。

## 可选 WSL 交叉测试

通过同一仓库在 WSL 的 `/mnt/d/` 映射目录内交叉测试（将占位目录替换为实际仓库路径），并使用临时数据根：

```bash
cd '/mnt/d/<实际仓库父目录>/<仓库目录名>'
preview_data="$(mktemp -d)"
ERP_DATA_ROOT="$preview_data" ERP_PORT=5001 PYTHONPATH=app .venv/bin/python app/app.py
```

应用入口从配置读取 host（默认 `127.0.0.1`），`ERP_PORT` 仅覆盖预览端口。请先确认 WSL 虚拟环境与 Windows 浏览器的 localhost 可达性；若需局域网绑定，必须另行评估免登录风险，不能把服务开放给不可信网络。退出服务后只清理本次创建的临时数据目录。

## 免登录边界

当前产品永久免登录；`/health` 公开。默认只用于本机回环地址，不能因页面能打开就认为已有权限保护。不要将服务改为监听 `0.0.0.0` 或暴露到不可信网络。历史登录计划不代表当前产品状态，决策记录见 `docs/需求/2026-07-26_永久免登录.md`。

## 交付纪律

1. 功能未到对应交付门，不通知用户当作可验收。
2. 不擅自 commit、升版、打 EXE、推送或发布；先确认本次授权范围。
3. 测试必须隔离正式业务数据库；真实 UI、EXE、打印机和 GitHub Release 各自需要对应证据。
4. 当前证据等级与结论保持一致：代码存在不等于真实运行，自动化测试通过不等于用户侧/打印机验收。
