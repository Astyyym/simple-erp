# 简单ERP 开发说明

## 启动

### WSL 源码开发（推荐 5001）

```bash
cd '/mnt/d/wenjian/Hermes/ERP系统'
source .venv/bin/activate
PYTHONPATH=app python -c "from erp import create_app; create_app().run(host='0.0.0.0', port=5001, debug=False, use_reloader=False)"
```

Windows 浏览器访问 WSL IP，例如：

```text
http://172.17.x.x:5001
```

不要与正式 EXE 的 `127.0.0.1:5000` 混用。

### Windows 脚本入口

- 第一次准备：`setup.bat`
- 日常使用：`启动系统.vbs` 或 `启动系统.bat`
- 停止：`停止系统.bat`
- WSL 双击入口（仅开发机）：`启动系统-WSL版.bat` / `停止系统-WSL版.bat`

## 测试

```bash
source .venv/bin/activate
PYTHONPATH=app pytest tests/ -q
```

健康检查：

```text
http://127.0.0.1:5001/health
```

正式 EXE：

```text
http://127.0.0.1:5000/health
```
