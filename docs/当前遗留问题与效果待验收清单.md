2026-09-25 产品审查曾确认两个订单账务缺陷：退货单重编辑会丢失负号；新建页面暴露后端不支持的状态，提交可能 500 并留下孤立客户。Phase 1 已修复上述问题及作废路径缺口。Phase 2 账款统一流水已实现，完整隔离测试 119 项通过，用户确认正确调整新增与浏览器 PDF 预览路径通过。Phase 3/4 实现与自动回归完成；Phase 3 原型人工验收通过。2026-09-26 Windows EXE 曾发现 PDF 预览无法返回 ERP；当前源码已改为来源感知的「返回上一级」，2026-09-30 fresh EXE 中由哥哥实际确认通过。其他桌面检查仍按原决定暂停。

本清单前半部分记录打印、视觉、统计/导入和桌面 PDF 保存的初始定向复核；当时没有足以判定具体故障的当前失败步骤，因此对应项按已证实事实与未验证状态分别记录。2026-09-25 后续产品审查另外通过隔离 SQLite 实测复现订单账务缺陷，并以源码核对确认其余体验缺口；这些新增项单独列明证据与修复状态。
