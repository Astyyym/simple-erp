# 永久免登录

日期：2026-07-26
状态：已确认
范围：开发 A（源码 + 测试）；不改 VERSION / README / CHANGELOG / 不 push / 不打包

## 背景

系统原先有单账号登录门（`local_access_*`，默认账号密码）。本地单机使用场景下，启动仍要输账号密码，增加摩擦。

## 目标

- **永久免登录**：浏览器与桌面 EXE 打开后直接进入业务页。
- **去掉登录 UI**：登录页不再作为入口；顶栏「退出登录」去掉。
- 访问 `/login`、`/logout` 时直接进入首页（或安全 next），不展示登录表单。
- `/health` 保持公开；`auth` 字段固定为 `disabled`。
- 配置默认关闭密码门，不再强制写入密码哈希。

## 非目标（本次不做）

- 多用户、改密 UI、可选再开登录开关
- 发版、GitHub 推送、EXE 重打包
- README / CHANGELOG / VERSION 同步（留给后续 B/C）

## 风险（已接受）

本机或局域网若能访问服务端口，即可直接进入系统操作数据。本产品定位为本地单机，接受该风险。

## 验收

1. 未设置任何 session 时，`GET /`、`/orders/new`、`/settings/`、业务 PDF/Excel 导出均 `200`（或业务正常状态），不跳 `/login`。
2. 页面无「退出登录」按钮；`/login` 不渲染用户名密码表单。
3. `/health` 返回 `auth: disabled`。
4. 相关 pytest 通过。
