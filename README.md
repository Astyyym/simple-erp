# 简单ERP

一个面向本地单机使用的小型进销存/开单系统，当前重点覆盖消防器材门店的日常销售开单、退货、客户账款、商品与客户资料管理、打印和本地数据保存。

## 当前版本

```text
v0.4.0
```

## 当前功能

### 桌面界面与录入体验

- 使用企业 ERP 风格工作台、分组侧边栏和统一的数据表格、表单及按钮样式。
- 销售单和退货单支持“一键清空”，清空后保留一行空白明细。
- 浏览器不会记录并弹出数量、单价、客户等历史输入；ERP 自身的客户与商品字典提示继续保留。
- 账款页使用聚合查询计算全部客户余额，减少客户较多时的等待。

### 开单与打印

- 新建销售单、退货单，录入界面一致。
- 订单编号格式：`MD` + 八位日期 + 四位流水，例如 `MD202607120001`。
- 销售单与退货单共用同一天流水号。
- 新建时日期默认当天、可改；改日期后单号按所选日自动重算；单号只读。
- 重编辑保持原单号与原日期，只改商品、价格、客户等业务内容。
- 支持保存后直接打开打印 PDF。
- 单据列表中退货单红色标注。

### 单据管理

- 原“单据查询”已更名为“单据管理”。
- 支持按年、按月到月（可跨年）、按日到日筛选。
- 支持订单类型筛选：全部 / 只看销售单 / 只看退货单。
- 唯一客户自动显示采购热力图与商品排行；模糊多个客户只列表并提示；空客户显示全店统计。
- 支持导出货款汇总表（新开 PDF 预览）：唯一客户单段，多客户分段；销售与退货都进表。

### 商品与客户资料

- 商品管理：新增、编辑、删除、批量删除、相似字符查询。
- 客户管理：新增、编辑、删除、批量删除、相似字符查询。
- 支持下载 Excel 模板与批量导入（xlsx/csv）；同名跳过不覆盖。
- 开单时输入新商品可沉淀到商品字典。
- 支持客户价/常规价。

### 账款管理

- 按客户查询订单，支持日期筛选与清除筛选。
- 查询结果中退货单红色标注。
- 客户余额：期初 + 销售 - 退货 + 调整 - 收款。
- 旧账款入口保留，可继续打印客户货款汇总表。

### 客户货款汇总表

- 可按客户和日期范围生成 PDF。
- 相同日期、单号合并单元格；退货行标红。
- 底部公式：销售总金额 - 退货总金额 = 总金额。
- 长单号在汇总表内自动换行，避免溢出。

### 回收站与数据安全

- 单据、商品、客户软删除。
- SQLite WAL；启动完整性检查。
- 运行数据、日志、临时 PDF、备份与源码分离。

### Windows 桌面版

- 支持打包为 Windows 桌面版 EXE。
- 使用方式：复制程序文件夹，双击 `消防ERP.exe`。
- 正式数据保存在程序目录 `data/erp.db`。

## 本地开发运行

### WSL / Linux 开发环境

```bash
cd '/mnt/d/wenjian/Hermes/ERP系统'
source .venv/bin/activate
PYTHONPATH=app python app/app.py
```

源码预览建议使用 `5001` 端口，避免与正式 EXE 的 `5000` 冲突。

### 运行测试

```bash
cd '/mnt/d/wenjian/Hermes/ERP系统'
source .venv/bin/activate
PYTHONPATH=app pytest tests/ -q
```

## 数据位置与升级注意

开发数据：

```text
data\erp.db
```

桌面版数据：

```text
data\erp.db   （EXE 同目录）
```

升级程序时不要覆盖正式电脑上的 `data\erp.db`。建议先备份整个 `data` 文件夹。
