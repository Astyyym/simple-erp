## 当前功能

### 开单与单据管理

- 销售单、退货单共用录入流程；商品单价取该客户的专属价（没有专属价就留空手输，手输价大于 0 会自动学成该客户对该商品的专属价）；新建默认保留一行明细，清空后恢复一行。
- 关闭浏览器对开单字段的历史自动填充，同时保留系统自身的客户/商品联想。
- 单号格式：`MD` + 八位日期 + 四位流水；销售单和退货单共用当天流水。新建日期可改，改单保留原日期和单号。
- 按客户、日期和单据类型筛选；日期支持按年、跨年按月区间及日期范围。
- 客户采购统计提供按日销售统计、日期热力图和商品排行；退货不计入采购统计。
- 货款汇总表支持 PDF 预览；销售单、退货单明细可导出 Excel。

### 客户、商品和账款

- 客户、商品基础资料维护、模糊查询、Excel 导出。
- 客户和商品支持 `.xlsx` / `.csv` 模板下载及批量导入；同名记录按当前导入规则跳过。
- 账款按客户汇总，涵盖期初余额、有效单据、收款和账务调整；客户往来流水区分全历史当前余额与筛选区间净变动；在「往来对账」里可导出 **A4 竖版对账单 PDF**（2026-10-14 起原「账款流水 PDF」已删除，其口径并入对账单）。
- 收款和调整支持带原因作废并保留审计记录；作废流水可追溯但不计入余额。
- 退货单在单据列表中与销售单区分显示；统计范围按各模块的当前业务口径计算。

### 拿货/退拿货、账款与分析

- **2026-10-16 起「库存 / 成本 / 利润分析」整体移除**（数据库结构 v15 已物理删除相关表与列）：不再有期初、安全库存、移动成本、库存状况、毛利与成本诊断。老库升级时会物理删除这些数据且**不可逆**，回退只能靠升级前自动生成的整库备份。
- 拿货/退拿货是与销售/退货并列的**纯流水单据**：共用统一往来对象、`NH` 单号、打印与对账并入、账款抵扣、回收站与当天历史；退拿货关联原单原行并控制可退额度（只做**追溯与额度**，不涉及库存或成本）。
- 商品档案只保留名称（唯一身份）、品牌、单位与备注；售价唯一来源 = 该客户的专属价（没有就留空手输，手输价大于 0 会学成该客户对该商品的专属价）。四类单据除「已作废」外都可编辑。
- 四类交易对账支持完整跨页选择和A4白名单打印；交易核对不自动登记收款、付款或结算，不替代客户欠款余额。
- 正式分析提供热力图、单据流水与产品排行，跨年展示、分页/排序/筛选保持，数量按同单位比较。

### 工作台与高频流程

- 工作台展示今日有效销售/退货净额与笔数，并列出最近 5 笔有效单据。
- 单据管理支持每页 50 条服务端分页、总数/范围提示和筛选条件保留。
- 客户/商品联想可用键盘选择，建议内容按文本安全显示；订单状态使用中文业务文案；退货重编辑保留负数金额，订单明细金额在建立新客户前校验。

### 设置、打印与桌面版

- 设置公司名称、主题（浅色/深色/跟随系统）、界面缩放、字体粗细（标准/稍粗/加粗）、打印文案、打印位置校准和数据根目录。
- 四类开单（销售/退货/拿货/退拿货）PDF 为 241mm 连续纸一联（逻辑页 215.9×139.7mm、页内左右各 7.3mm 版心）；客户货款汇总、往来对账单 PDF 为 A4 竖版（210×297mm）。两套纸型不得混用。（2026-10-14 起账款流水 PDF 已并入对账单。）
- 打印驱动建议选择 A4 横向、实际大小/100%，关闭“适合页面/缩放”（连续纸由驱动居中映射）。横纵偏移与缩放作用于四类开单及设置样张，不作用于账款汇总和往来交易对账。
- 目标打印机实打**已验收**（2026-10-12，用户侧人工验收）：10 行单 / 11 行单已在门店机器上实际打印，纸面位置与字迹确认正确。PDF 页框正确与实机纸面位置此前是两件事，现已一致。历史 `NantianPR-LQ` 驱动选项在实际设备上核对通过。用户于 2026-10-12 确认全部遗留验收项通过。
- 新建销售/退货单保存成功后，右侧同页显示当前单据的真实 PDF；可关闭、重新打开、缩放屏幕显示、保存 PDF 和打印。屏幕缩放不改变 A4 PDF 排版；保存失败不会打开预览。
- Windows 桌面版为 PyInstaller one-folder 程序；业务数据目录与程序文件分开，升级时不要覆盖用户数据。
- 提供两种分发形态：**安装包**（`simple-erp-setup-vX.Y.Z.exe`，per-user 安装到 `%LOCALAPPDATA%\Programs\简单ERP`，带开始菜单/桌面图标与卸载入口，升级不覆盖 `config.json`、卸载不删数据）和**绿色包**（解压即用）。绿色包**自带 200 条演示数据**（包内 `demo_data\`，双击打开即可预览，随便试）；安装包与交付 ZIP 是给门店用的正式程序，**不含任何演示数据**。

## 重要安全边界

当前版本**永久免登录**。程序面向本机单机使用，默认仅监听 `127.0.0.1`；任何能访问服务端口的人都可操作业务数据。带有 `Origin` 或 `Sec-Fetch-Site` 的浏览器写请求执行同源检查，但这不是身份认证。不要把服务绑定到 `0.0.0.0`、开放到局域网或公网。`/health` 为公开健康检查端点，返回 `auth: disabled`。

## Windows 桌面版打包

一条命令出齐三种交付产物：

```bat
打包Windows安装包.bat
```

| 形态 | 产物 | 用途 | 演示数据 |
|---|---|---|---|
| 绿色版目录 | `dist\local-v4.2.0\简单ERP\` | 本机/U 盘直接跑（双击 `简单ERP.exe`，**不需要安装**） | **自带 200 条** |
| **安装包** | `dist\simple-erp-setup-v4.2.0.exe` | 门店用户双击安装，带开始菜单/桌面快捷方式与卸载项；per-user，不需要管理员 | 无 |
| 交付 ZIP | `dist\simple-erp-windows-v4.2.0.zip` | 发给别人，解压即用 | 无 |

**绿色包里有 200 条测试数据**：200 张单据（销售 / 退货 / 拿货 / 退拿货合计）加演示商品、客户与账款流水，双击 `简单ERP.exe` 打开就能看到单据管理里的历史单、能改能删，**适合先预览效果再决定要不要装**。演示数据在包内 `demo_data\`，**与机器上的正式数据（「文档\简单ERP数据」）物理隔离**，不会写进真实账本，整个文件夹可拷到 U 盘。

安装包与 ZIP 是同一份程序（正常入口构建），**不含演示数据**，装好 / 解压后是空账本，从零开单。绿色版是**另一份构建**（演示入口 `packaging/demo_entry.py`，把数据根强制指向包内 `demo_data`）。安装包装到 `%LOCALAPPDATA%\Programs\简单ERP`（向导里可改路径），业务数据在「文档\简单ERP数据」，安装/升级/卸载都不动它。

**认名字**：安装包带 `setup` 字样；`简单ERP.exe` 是绿色版主程序，双击直接开、不走向导——这是设计如此。

源码及健康/UI/Windows产品版本均为 `v4.2.0`，Windows数字文件版本为 `4.2.0.0`。安装包与 ZIP 内含通用配置，不含业务或演示数据库；绿色版含出厂配置与 `demo_data\` 演示数据。

旧版打包脚本 `打包Windows桌面版.bat` 只出绿色版目录（不发版用）；发版请用上面的脚本。

常规脚本的常见产物：

```text
dist\简单ERP\简单ERP.exe
dist\simple-erp-setup-vX.Y.Z.exe
dist\简单ERP-Windows桌面版-vX.Y.Z.zip
dist\simple-erp-windows-vX.Y.Z.zip
```

详细步骤、数据目录和升级边界见 [`docs/Windows桌面版打包说明.md`](./docs/Windows桌面版打包说明.md)。本地 `dist/` 文件存在或源码测试通过，都不能单独证明 GitHub Release 已上传或桌面 EXE 已通过实机验收。

## 升级时的数据保护

1. 退出程序并备份当前设置页显示的整个数据目录，保留原程序配置 `config.json`。
2. 更新程序文件；不要用安装包中的空库覆盖正在使用的 `data\erp.db`。
3. 若旧安装仍把数据放在程序旁的 `data\`，尤其不要整目录覆盖。
4. 启动后检查版本和历史单据是否仍在。
5. `v3.6.0` 首次连接旧库会执行内置结构升级；不要升级后直接用旧程序打开新库。**结构升级不可逆**：升级前的库存与成本数据会被物理删除，回退只能靠迁移前自动生成的整库备份。本地打包验收不等于已经迁移正式数据。

用安装包升级时不需要先卸载：直接运行新版本安装包即可，它会覆盖程序文件、保留 `config.json` 和业务数据。卸载程序同样不会删除数据目录。
