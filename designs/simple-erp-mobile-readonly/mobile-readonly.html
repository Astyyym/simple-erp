这一版做了什么

  • 视觉已定 B（原生 App），A 仍可切换，仅作对照
  • 今日概览已定时间轴版式：顶部两个净额小卡 + 按时间倒序的事件流，两段小计仍保留
  • 7 个页面：今日概览、客户列表、客户详情、单据列表、单据详情、商品价、配对页
  • 列表金额只给分档（无欠款 / <1千 / 1千–1万 / >1万），精确金额进详情才出
  • 商品价：专属价与最近成交横向并排，一屏能多看几条
  • 某类为 0 仍然占一行
  • 顶部留了 26px 状态栏安全区（刘海屏取 env 实际值），全部触控目标 ≥ 44px

可点的路径

  • 今日概览 → 任一类型行 → 单据列表
  • 单据列表 → 单据 → 单据详情
  • 客户 → 客户详情 → 历史单据
  • 商品价：专属价与成交价不一致时给提示
