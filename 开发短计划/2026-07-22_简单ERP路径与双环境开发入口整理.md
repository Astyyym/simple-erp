# 2026-07-22 简单ERP路径与双环境开发入口整理

## 目标

保持“同一份 Windows D 盘源码，Windows 主开发/验收，WSL 按需交叉测试”的架构，修复项目改名后的失效路径，并固定 WSL 预览端口为 5001、Windows 正式端口为 5000。

## 修改范围

1. `启动系统-WSL版.bat`、`停止系统-WSL版.bat`：更新目录并统一使用 5001。
2. `README.md`、`docs/开发说明.md`、`docs/Windows桌面版打包说明.md`：更新“简单ERP”正式路径与双环境职责。
3. Hermes Desktop：新建/绑定“简单ERP”项目到 `D:\wenjian\Hermes\简单ERP`。

## 不修改

业务逻辑、数据库、Windows EXE 的 5000 端口、版本号、Release 和打包产物。

## 验证

- Windows 与 WSL 均访问同一 Git 仓库；
- WSL `.venv/bin/python` 可用，Windows `.venv-win` 可用；
- WSL 启停脚本不再出现旧目录，启动目标为 `0.0.0.0:5001`；
- Windows 正式入口仍为 `127.0.0.1:5000`；
- 运行测试、`git diff --check` 与旧路径扫描。
