### 1.2 写码前技术决策（默认，有冲突先改这里再动手）

| 点 | 决策 |
|----|------|
| 统计区出现条件 | 筛选值**精确匹配唯一**未删除客户；模糊多命中不展示 |
| 拿货统计谓词 | `order_type='sale'` 且 `status IN ('saved','printed')` 且 `deleted_at IS NULL`；退货/草稿/删除不计 |
| 热力图颜色 | 只由当天销售总金额决定；档位按**当前客户+当前区间**动态分级 |
| 排行排序 | 默认累计**数量**降序；金额并列展示；并列再按金额、品名稳定排 |
| 数量字段 | 文本 quantity 安全转数值；非法当 0，不 500 |
| 图表 | 本地静态或纯 SVG/Canvas；**禁止运行时 CDN 图表库** |
| 看板数据下发 | 服务端聚合 → 模板专用 `<script type="application/json">`；前端只渲染 |
| 单击 vs 拖选 | 单击查当天；指针实际跨格才进范围选择；松手先确认条再跳转；反向拖规范化起止 |
| 列表类型筛选 | 全部/销售/退货可组合；切换保留客户与日期；与热力图「只统计销售」语义分离 |
| 导入商品模板 | 列：商品名称、价格；默认单位「个」；价元→分 |
| 导入客户模板 | 列：客户名称；电话/地址空；期初 0 |
| 同名策略 | 在库同名、软删同名、文件内重复 → 跳过；不覆盖、不恢复 |
| 导入结果 | 直接渲染或 flash；错误列表截断（如前 50～100）+ 总数；**不塞超长 query** |
| 文件限制 | 仅 `.xlsx`/`.csv`；约 5MB；CSV：UTF-8 / BOM / GB18030 |
| 日期参数 | 非法安全回退；起>止归一；超大跨度上限/降级；避免最大日期 `+1 day` 溢出 |
| 开发端口 | 正式桌面 **5000**；WSL 开发预览 **5001**（或明确 WSL_IP:5001），禁止与旧 EXE 混入口 |
| Git | 功能确认前不默认 push；建议分支 `feature/customer-analytics-import`（开工时按仓库现状定） |

## 4. 交互状态机（阶段 3 必守）

```text
指针按下某日格子
  → 记录起点；尚未提交查询
指针移动到其他日
  → 标记「跨格拖选」；高亮规范化 [min,max]
指针在同一格松开 + 未跨格
  → 视为单击：立即查询当天（客户 + start=end=该日）
指针跨格后松开
  → 不跳转；显示已选起止 +「查看订单详情」+「取消选择」
点「查看订单详情」
  → 复用 /orders/，带入客户与起止，执行查询
点「取消选择」
  → 清除拖选 UI，保留原筛选

热力图/排行：永远只聚合有效销售
列表类型筛选：可看退货，与上互不混淆
```

边界：无单据客户、无日期参数（回退该客户实际最早最晚）、单日、跨月、反向拖、非法日期、极端跨度。
