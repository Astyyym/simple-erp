# Issue #2 桌面打印免二次登录

> 历史执行记录：仅描述 v0.5.0 阶段的登录行为和当时验收状态。v0.8.0 起永久免登录；当前行为以 `docs/需求/2026-07-26_永久免登录.md`、源码和测试为准。

- 分支：`fix/issue-2-desktop-print-auth`
- 基线：`main` @ v0.5.0 / `5a17e63`
- 状态：实现中 → 测试 → commit（不 merge / 不发版）

## 根因

桌面 pywebview 已登录后，打印入口用 `target=_blank` / `window.open` 甩到系统浏览器；两边不共享 session cookie，因此再进 `/login`。

## 方案

**方案 A（主方案）**：桌面壳内同窗口打开打印/PDF/预览，不再外开浏览器。

- `ERP_DESKTOP=1` → 模板 `is_desktop=true`、`data-desktop="1"`
- 打印链接去掉 `target=_blank`
- 开单保存后 `openPrintUrl()` → `location.assign(pdf_url)`
- 普通浏览器仍 `_blank` + 登录门不变（历史规则，已被 v0.8.0 永久免登录取代）
- 不采用全局免登录 / 不写长期密码 URL

## 改动面

- `app/erp/auth.py`：`is_desktop_shell()`
- `app/erp/__init__.py`：注入 `is_desktop`
- `app/erp/templates/base.html`：`openPrintUrl` / `isDesktopShell`
- 打印入口模板：orders new/list/detail、accounts、settings
- 测试：`test_print_workflows.py`、`test_desktop_print_auth.py`

## 验收

- 桌面已登录：开单打印 / 列表打印 / 汇总 PDF / 设置预览 → 不二次登录
- 浏览器访问业务页无需登录；此处“未登录跳 `/login`”仅为 v0.8.0 以前的历史验收条件，现已失效。
- `/health` 匿名可访问
- pytest 通过；commit `Fixes #2`
