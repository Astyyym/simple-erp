## 一、背景与结论

用户实打销售单「预览正常、实打偏下偏左」。排查后确认：

| 现象/数据 | 结论 |
|-----------|------|
| 一联撕开后尺子 | 宽约 **240mm**，高 **140mm** |
| 两联未撕 | 高约 **280mm**（140×2） |
| 包装/旧文档 | 常写 241×280 或 288，指连张或标称，**不是一联 PDF 页高** |
| 左孔带到正文 | 约 **20mm** |
| 纸型 | **二联纸**；一单一页 PDF，二联叠打 |
| 旧系统 | `printer_paper_height_mm=280` + 流式 padding → 按两联总高画一页，版心相对真纸漂 |

**本轮纸张规格（拍板）：**

| 项 | 值 |
|----|-----|
| PDF / 打印机自定义纸 | **241mm × 140mm** |
| 宽 | 241（行业标称；实测 240，差 1mm 可忽略） |
| 高 | **140**（一联撕开后） |
| 左安全边 | **20mm**（孔边→正文） |
| 右安全边 | **20mm**（与左等宽，版心居中） |
| 上/下 | 初值 6mm |
| offset | 默认 **0**；仅机差 1–3mm 再用设置页校准 |
| 三联/二联 | **一单一页**；叠打不增高 PDF |

280/288：**禁止**再作为单页高度。

## 二、版面分区（241×140）

```
宽 241 | 高 140
左 20 | 右 20 | 上 6 | 下 6
可打区 ≈ 201 × 128 mm

上区 ~20mm：公司名、销售清单、单号/日期/客户
中区 弹性：明细表 + 合计行（名称规格约 72mm，其余列固定加宽）
下区 ~32mm：电话/地址/主营/备注 + 制单人/收货人（footer-grid）
```

原则：

1. `@page` 与 `.page` 固定 **241×140**，`margin:0`，`height` 固定勿只靠 min-height 漂。
2. **左右 padding 等宽 20mm**：左对齐孔边实测，右对称，标题/表格相对纸面居中（不是只在左偏内容区居中）。
3. 名称规格列固定约 **72mm**，不再吃掉整行剩余宽度。
4. 字号整体小于 280 高旧版；页脚钉在下区。
5. 保留 `print_offset_*` / `print_scale` 挂钩，默认 0/1.0。
6. 设置预览与订单 PDF 同一 `print_template.html`。
