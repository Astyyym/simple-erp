# 开发短计划

本目录存放 ERP 功能开发的**可执行短计划**，与正式需求文档、复盘文档区分：

| 类型 | 位置 | 用途 |
|------|------|------|
| 需求文档 | [`docs/需求/`](../docs/需求/) | 业务规则与验收标准（长期） |
| 复盘文档 | [`docs/复盘/`](../docs/复盘/) | 失误归因与纪律（长期） |
| 开发说明 | [`docs/`](../docs/) | 启动、打包等操作说明 |
| **短计划** | `开发短计划/` | 某次开工的阶段、决策、清单、状态（执行用） |

## 约定

1. 文件名：`YYYY-MM-DD_主题_执行计划.md`
2. 一份短计划对应一次可交付目标；做完在文内更新「当前状态」
3. 短计划服从复盘中的五阶段状态：开发中 → 已实现 → 已测试 → 已运行验证 → **可验收**
4. 未到「可验收」不得通知用户打开页面验收
5. 用户确认功能后，再决定 git / 版本 / EXE；短计划不得默认包含擅自发版
