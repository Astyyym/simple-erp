# 数据分析柱状图「竖向生长」动画（2026-10-10）

## 目标

数据分析页的条形统计图在**切换到它时**播放一次竖向生长动画：柱子从基线长到最终高度。

- **匀速**：所有柱同一生长速度（px/秒），因此**矮柱先到顶、高柱用时更长**；线性，不做缓动（缓动会让各柱快慢不一致）。
- **只改出现方式**：柱高、数值、排序、比例尺、后端口径全部不变。
- **触发时机（用户明确，两轮确认）**：**切换图表就播**。
  - 播：点「产品排行」页签、点「成本诊断」页签、**换榜（排行下拉：热销/低销量/退货抵销/未销售/毛利润/库存告急）**、**换每组显示条数**、点「显示」、成本视图环形 ↔ 堆叠条。
  - 不播：打开页面（整页加载）、整页筛选重查、点已选中的页签。
  - 说明：第一轮按「只有切页签才播」实现；第二轮用户指着产品排行的「排行」下拉明确要求「这几个进行切换的时候，也需要有动画」，故把就地刷新也纳入触发点。

## 范围（用户确认「按你倾向的来」）

| 图表 | 形态 | 动画 |
|---|---|---|
| 产品排行（六种榜） | 竖向柱 | 竖向生长（匀速） |
| 成本缺失来源 | 竖向柱 | 竖向生长（匀速） |
| 成本覆盖 / 毛利构成 | 横向堆叠条 | 从左向右匀速展开（同一「匀速」规则，横向按自身像素宽度标定速度） |
| 成本环形 | 环形 | 维持既有 12 点顺时针扫掠，本次不改 |

## 实现要点

1. **不用纯 CSS 动画**：结果区块是 `refreshInPlace` 整块替换的，纯 CSS 动画会在每次就地刷新时重放（等于「换榜也播」）。改为 **JS 在切换时加 `.is-growing` 类**，刷新后类随旧节点一起消失，天然不重放。
2. **每根柱的时长 = 柱高 ÷ 速度**（速度常量 `BAR_GROW_SPEED_PX_S = 240`，最高柱 190px ≈ 0.79s，与环形扫掠 0.8s 同节奏）。时长写在柱元素上的 `--bar-dur`，柱高写 `--bar-rise`。
3. **柱顶数值随柱顶上升**：`.rank-bar-value` 与柱同用 `--bar-rise`/`--bar-dur`，动画 `translateY(rise) → translateY(0)`，保持 `translateX(-50%)` 基座。
4. **堆叠条**用容器级 `clip-path: inset(0 100% 0 0) → inset(0 0 0 0)` 从左向右展开（不做 `scaleX`，避免把条内文字压扁）；时长 = 容器像素宽 ÷ `STACK_GROW_SPEED_PX_S = 700`。
5. 隐藏的图表（`[hidden]` 祖先）不播；点已选中的页签不播；`prefers-reduced-motion: reduce` 时 JS 直接跳过（CSS 侧再关一次）。

## 验收证据

- **E1 自动**：`node --test tests/frontend/`（新增：时长与柱高成正比、速度一致、隐藏/减少动态时跳过、堆叠条按宽度定时长）；`pytest tests/test_analytics_v4_behavior.py tests/test_quantity_display.py tests/test_analytics_center.py`；再跑全量 pytest。
- **E2 真实页面**（隔离数据根 + CDP，不用截图判断）：页内 rAF 采样柱高，
  ① 切换页签后柱高从 0 单调长到最终值；
  ② 各柱「高度 ÷ 用时」在容差内一致（同速度）、最高柱用时最长；
  ③ 打开页面 / 换榜就地刷新后**无生长**（高度直接是终值、无 `.is-growing`）；
  ④ `Emulation.setEmulatedMedia` 置 `prefers-reduced-motion: reduce` 后切页签直接到位。
- **非目标**：不改利润口径、不改环形、不加新图型、不打包/升版/发布。

## 停止条件与风险

- 若真实页面采样显示速度不一致（例如时长被浏览器吸附到帧），先回到「按时长=高度/速度」核对，不动后端。
- 若堆叠条 `clip-path` 在目标浏览器表现异常（如边框闪），回滚堆叠条动画，只保留竖向柱生长（竖向柱是本需求主体）。
- 上一轮「环形与成本缺失竖向」改动仍在工作区未提交，本轮只在其之上叠加，不回退、不清理。
