1. 升版 + 文档收口 + 测试去硬编码。
2. 全量 pytest（Windows `.venv-win`）+ 前端 Node 测试。
3. fresh PyInstaller one-folder 构建 → `dist/local-v3.1.0/`（独立 dist/work，不覆盖旧包）。
4. 隔离数据根冒烟：`/health` 版本、关键页面、包内 config 为通用模板、**确认无 `data/erp.db`/`demo_data`**。

6. `git add` 白名单（排除 `config.json`/`demo_data`/根任务记录），`git diff --cached --check`，提交，推送 `main`。
7. 打 tag `v3.1.0` 并创建 GitHub Release，上传 ASCII 命名的 ZIP；重新查询 Release 核实资产。
8. 交付 ZIP 路径给用户。
