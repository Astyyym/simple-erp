## 目标

在新建销售/退货单点击「保存/打印订单」并成功保存后，保留当前开单页面，在右侧同页展开打印预览；中间开单区域同步缩窄，动画约 250–300ms。面板按钮从左到右为「关闭预览」「保存 PDF」「打印」，按钮之间留有清楚间距，并另设独立的「缩小 / 100% / 放大」缩放控制。左侧导航以约 200px 为目标收窄；预览承载面板紧凑贴合A4预览，避免纸张下方大块空白。关闭预览后仍回到当前开单页和已保存内容，不另开独立窗口，也不覆盖整张 ERP。

## 范围与边界

- 保留销售/退货的保存、单号、账款、PDF 内容、A4 竖版纸张规格和现有 PyWebView 原生「保存 PDF」能力；打印按钮针对当前单据的 PDF，不是打印整个 ERP 页面。
- 缩放只控制屏幕上的真实 PDF 固定页面的显示比例；PDF 内部排版、字体换行、A4 页框、打印模板及设置偏移均不改变。不得用 HTML 样张的 CSS zoom 重排冒充 PDF 缩放。
- 仅在保存成功后自动展开预览；保存失败时留在当前表单并显示错误。
- 在同一布局中提供关闭预览；成功提示中的手动预览入口也应打开同一右侧面板。
- 不改打印模板、PDF 排版/偏移、路由业务语义、数据库结构或正式数据；本轮升至 V1.1.0 并打本地包，不提交或推送。
- 先以虚构内容建立可交互原型并在 Hermes Desktop 侧边预览验收；之后才进入正式实现。
