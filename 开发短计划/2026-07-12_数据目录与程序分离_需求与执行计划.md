## 二、已拍板规则（倾向选项落地）

### 2.1 路径记忆（1B）

- 记录文件放在 Windows 用户目录，不跟程序夹走：  
  `%LOCALAPPDATA%\简单ERP\data_location.json`
- 内容仅路径与元数据，例如：  
  `{"data_root": "D:\\...\\某文件夹", "set_at": "...", "version": 1}`
- **不把业务库写进 LocalAppData 本体**（除非用户主动把数据目录选到那里）

### 2.2 首次启动默认（2B）

- 推荐默认：`%USERPROFILE%\Documents\简单ERP数据`
  （展示名可用「文档\简单ERP数据」）
- UI：  
  - 显示推荐路径  
  - **使用推荐目录**  
  - **选择其他文件夹**（系统原生选夹）  
- 确认后写入 `data_location.json`，再初始化子目录与数据库

### 2.3 更改数据目录（3C）

- **本版不做**设置页「迁移/改目录」
- 以后若要改：另开需求（复制/迁移旧库 + 改 json）
- 本版仅：首次选择（及旧版迁移提示，见 2.4）

### 2.4 旧版兼容（4A）

正式 EXE 启动时若：

1. 尚无有效 `data_location.json`，且  
2. 程序旁存在 `data\erp.db`（旧绿色版布局）

则提示（文案大意）：

> 发现本程序目录下已有旧版数据，是否继续使用该文件夹作为数据目录？

- **是** → `data_root = <exe 目录>\data` 的父级约定：  
  **登记 `data_root = <exe 目录>`** 且继续使用现有 `data\erp.db` 布局  
  （即仍兼容「exe 旁 data\erp.db」，只是把路径记住，升级时用户勿覆盖 data）  
  更干净的等价表述：登记 `data_root = <exe 目录>`，库路径仍为 `{data_root}/data/erp.db`。
- **否** → 走首次选择流程；**不自动删除**旧库

> 实现时统一：`erp.db` 始终在 `{data_root}/data/erp.db`。  
> 旧版「exe 旁已有 data\erp.db」⇔ `data_root = exe 所在目录`。

### 2.5 数据目录内容（5A）

`{data_root}/` 下：

```text
data/erp.db
backups/
imports/
logs/          # 业务/运行日志一并迁到数据根，避免升级清程序时丢排障信息
temp_pdf/      # 打印临时文件
```

- `config.json`：仍可在程序旁（应用配置）；若需覆盖升级配置，与数据无关  
- 安装包 / Release zip：**不包含**用户业务 `erp.db`

### 2.6 首次选夹交互（6A）

- 桌面 EXE：`tkinter.filedialog` 或等效 **Windows 原生文件夹对话框** + 简短确认窗  
- 在 `create_app()` / Waitress 起服务**之前**完成选目录（`desktop_app.py` 启动序）  
- 未选定前：不初始化业务库、不假装启动成功  
- 用户取消选择：退出或提示必须选择（不可静默写到错误位置）

### 2.7 开发与 EXE（7B）

同一套路径解析：

| 环境 | 行为 |
|------|------|
| **EXE（frozen）** | 读 `%LOCALAPPDATA%\简单ERP\data_location.json`；无则首次引导 / 旧库探测 |
| **源码开发** | 默认 `data_root = 项目根目录`（继续用仓库旁 `data/erp.db`，无需弹窗） |
| 覆盖开关 | 支持环境变量如 `ERP_DATA_ROOT`（测试与排障），优先级高于 json |

## 四、启动顺序（EXE）

```text
1. 读 ERP_DATA_ROOT（若有）→ 用它
2. 否则读 %LOCALAPPDATA%\简单ERP\data_location.json
3. 有效 data_root → 确保子目录 → create_app → 服务
4. 无效/不存在：
   a. 若 exe 旁存在 data\erp.db → 询问是否沿用（是则登记 data_root=exe 目录）
   b. 否则首次 UI：推荐 Documents\简单ERP数据 / 自选文件夹
   c. 写入 json → 确保子目录 → create_app → 服务
5. 用户拒绝选择 → 友好退出
```

## 五、升级说明（将来写给用户/Release）

1. 退出简单ERP  
2. 用新版覆盖 **程序文件**（`简单ERP.exe`、`_internal` 等）  
3. **不要**指望安装包带数据；数据在用户已选目录  
4. 若仍有人把整个旧绿色版文件夹当数据目录（2.4 沿用），覆盖时仍须避免抹掉该夹下 `data\`——文档中单独警告「沿用旧布局」用户  

目标态：大多数新用户数据在「文档\简单ERP数据」或自选盘，与程序夹分离，整夹覆盖程序也丢不了单。
