# Issue #8 桌面端打印预览保存 PDF

- Issue: #8
- 状态: 自动化验证完成，待 Windows EXE 真机验收

## 根因

为复用 pywebview 登录会话，桌面端将 PDF 保留在壳内打开；内嵌 PDF 查看器没有稳定的下载或另存入口。

## 实现方案

1. 桌面端 PDF 链接增加 `desktop_preview=1`，服务端返回带工具栏的预览页。
2. 预览页仍用同一会话加载原始 PDF，保证内容和纸张尺寸不变。
3. 点击“保存 PDF”后，页面读取当前 PDF，调用 pywebview 原生保存对话框并写入用户选定位置。
4. 取消保存不报错；保存失败显示错误，不影响继续查看或打印。
5. 浏览器端继续直接打开 PDF，不改变原有下载/打印流程。

## 覆盖范围

- 销售单、退货单 PDF
- 单据管理货款汇总表
- 客户账款汇总表
- 设置页打印预览：已增加真实 PDF 入口，保留原 HTML 快速预览
