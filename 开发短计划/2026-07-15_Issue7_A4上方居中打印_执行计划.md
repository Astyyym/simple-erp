# Issue #7 A4 上方居中打印

- Issue: #7
- 状态: 已在 v0.7.2 修复并关闭

## 现象

销售单 PDF 预览正常，但在 NantianPR-LQ 驱动实际打印时发生位置或版面错误。此前模仿秒账使用 215.9×139.7mm 的特殊 PDF 页面，Windows A4 驱动会再次处理其居中和缩放。

## 修复方案

1. 销售单改为标准 A4 横向 PDF（297×210mm）。
2. 保留实体二联纸单据区 241×140mm，放在 A4 页面上方居中。
3. 单据区左右各留 28mm，下方留白；内容从上方排布。
4. 打印说明统一为 A4 横向、实际大小 100%、不要缩放。
5. 保留毫米偏移与缩放配置，供真机细调。

## 验收

- [x] PDF 页面为 A4 横向
- [x] 单据区为 241×140mm 且上方居中
- [x] 回归测试通过
- [x] Windows EXE 打包并发布 v0.7.2
- [x] Issue #7 关闭
