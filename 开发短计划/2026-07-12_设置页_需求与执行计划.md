## 一、目标

单开 **设置页**，让店里在界面内完成：

| 能力 | 说明 |
|------|------|
| 公司名称 | 只改一处 → 顶栏、销售单 PDF、退货单 PDF、账款汇总 PDF 抬头全部同步；**系统名称 `app_name` 与公司名同步** |

| 未保存提醒 | 改设置后切换页面：保存并离开 / 不保存离开 / 取消 |

- 无有效 location 时，**静默使用默认数据根**（见 2.2），写入 `data_location.json` 后正常进系统。  
- 用户之后在 **设置页** 查看默认路径并按需更改 + 迁移。

## 二、已拍板规则

### 2.1 入口与权限

- 侧栏新增 **设置**（建议放在「基础资料」分组末或独立「系统」分组；实现时与现有 nav 风格一致）。  
- 路由建议：`/settings/`（GET 页面）、保存用 POST 或分块 API。  
- **本版不加**设置页密码保护。

### 2.2 数据存储位置

| 项 | 规则 |
|----|------|
| 记忆文件 | `%LOCALAPPDATA%\简单ERP\data_location.json`（仅路径元数据，不把业务库塞进 LocalAppData 本体） |
| 默认 `data_root` | `%USERPROFILE%\Documents\简单ERP数据`（展示可用「文档\简单ERP数据」） |
| 库路径约定 | `{data_root}/data/erp.db`；同级保留 `backups/`、`imports/`、`logs/`、`temp_pdf/` |
| 首启 | 无有效 json → 用默认根 → 确保子目录 → 写 json → 启动业务（**不弹强制选夹**） |
| 设置页展示 | 当前路径、默认路径说明、「更改目录」 |
| 更改目录 | **一键迁移**：将旧根下业务相关内容拷到新根，校验后再改 json 指向；失败则保持旧指向并报错 |
| 环境变量 | `ERP_DATA_ROOT` 仍可强制覆盖（开发/排障），优先级高于 json |
| 源码开发 | 默认可继续项目根 `data/erp.db`（与 EXE 默认 Documents 区分）；设置页在开发模式下也要能展示当前解析结果，避免误导 |

**迁移范围（默认，实现时写死并测）**

- 必须：`data/`（含 `erp.db` 及 `-wal`/`-shm` 若存在）  
- 建议一并：`backups/`、`imports/`、`logs/`（`temp_pdf/` 可重建，可不迁或空迁）  
- **不删除**旧目录（除非日后另开「清理旧目录」需求）；迁移成功后提示「已切换；旧目录仍保留可手动删」  
- 新目录若已存在非空 `data/erp.db`：默认 **中止并提示**，避免静默覆盖（安全默认）

**生效方式**

- 保存路径/迁移成功后：优先 **进程内切换** `data_root` 并重绑 DB；若实现成本过高，则 **提示重启 EXE** 后生效——实现阶段二选一写进代码注释与 UI 文案，验收时以「改完后订单仍读写新库」为准。

### 2.3 公司名称 / 系统名称

- 设置页 **只提供一个「公司名称」输入框**。  
- 保存时同时写入：  
  - `shop_name`（打印抬头、业务展示）  
  - `app_name`（系统名称，与公司名 **同步为同一字符串**）  
- 驱动范围：  
  - 顶栏 `.company`（去掉硬编码「简单ERP」）  
  - 销售单打印模板 `h1`  
  - 退货单打印（与销售共用模板则自然同步；若有独立标题逻辑不得写死旧名）  
  - 账款汇总 PDF `h1`  
  - 浏览器/窗口标题若使用 `app_name` 一并更新  

### 2.4 显示缩放（仅 Web UI）

- 档位：**100% / 125% / 150%**（单选或等价控件）。  
- 作用：页面 UI（侧栏、开单表、列表、设置等）。  
- **不**改变打印 PDF 的 mm 布局、`print_scale`、纸张 241×280。  
- 放大可能导致视口内容被裁切 → **主内容区（及需要处侧栏）必须可滚动**（横向/纵向按实际溢出加 scrollbar，禁止「放大后按钮点不到且拖不动」）。  
- 持久化：写入可写配置（见 2.7），刷新/重启后恢复。

### 2.5 主题（仅界面）

- 三选一：**浅色 / 深色 / 跟随系统**。  
- 仅 CSS/界面 token；**打印 PDF 永远白底黑字**。  
- 「跟随系统」：桌面版读操作系统浅/深色偏好（WebView/CSS `prefers-color-scheme` 即可）。  
- 持久化同 2.7。

### 2.6 打印布局信息（固定位置填空 + 预览）

**版式结构不改**（仍为：抬头 → 副标题 → 元信息 → 表格 → 下方信息区）。  
用户在设置里看到的是 **对应位置的文本框**，填什么打印就出什么；**不是**毫米拖拽排版器。

| 字段 | 是否可配 | 说明 |
|------|----------|------|
| 公司抬头 | 是 | 即公司名称（与 2.3 同一数据源，设置页可只在「公司」区编辑一处，打印区只读展示或同源） |
| 副标题「销售清单」 | **否** | 不提供修改 |
| 订货电话 | 是 | 替换现模板硬编码电话串 |
| 订货地址 | 是 | |
| 主营业务 | 是 | |
| 备注（法律效力等固定句） | 是 | 订单 `notes` 仍可拼在其后；固定句走配置 |
| 制单人 | 是 | 现硬编码「REDACTED_CONTACT」 |
| 收货人 | 是 | 默认可为 `收货人：____________` 一类整段文案；用户可改文案/下划线习惯 |

**明确不做（本版）**

- 副标题文案配置  
- 拖拽/坐标级排版  
- 销售/退货两套完全不同的页脚配置（**共用一套**打印页脚字段）  
- 改纸张尺寸业务规则（仍用现 `printer_paper_*`；偏移/scale 若已在 config 可只读展示或下期再进设置）

**预览**

- 设置页提供 **「预览打印效果」**：生成/打开预览页（示例数据即可：假单号、假客户、1～2 行商品），所见即所得核对抬头与页脚。  
- 预览不得写脏正式业务库（用内存/临时样例渲染）。

### 2.7 配置存放

| 数据 | 位置 |
|------|------|
| `data_root` | `%LOCALAPPDATA%\简单ERP\data_location.json` |
| 公司名/app_name、打印文案、主题、缩放、打印偏移等应用配置 | **可写 `config.json`**（路径解析与现 `load_config` 一致；EXE 写 runtime 可写配置，避免只改 `_MEIPASS` 包内只读副本） |
| 业务库 | `{data_root}/data/erp.db` |

保存设置后：`load_config` 缓存需失效或进程重载配置，保证下一张 PDF/下一页顶栏立刻用新值（至少保存成功提示后刷新页面可见）。

### 2.8 默认值（从当前模板迁出）

首次无键时写入与现网一致的默认，避免升级后打印空白：

- 公司名 / app_name：现 `shop_name`（如简单ERP）  
- 订货电话、地址、主营、备注、制单人、收货人：与当前 `print_template.html` 硬编码一致  
- 主题：浅色（或跟随系统，实现时选一默认并写进计划验收：建议 **浅色** 稳妥）  
- 缩放：100%
